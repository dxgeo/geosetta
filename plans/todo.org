* Current Working Items
Live list of what's open right now — not the full historical plan index (see
[[file:README.org][README.org]] for that, ordered by dependency, everything
DONE included). Each entry is just a link to its real plan/section for detail;
check it off and remove it once the item ships or is shelved.

- [ ] [[file:same-format-output.org][same-format-output.org]] — drop the
  =args.from == out.format= rejection so a user can write the format they read.
  Geosetta is now the ecosystem's only reader/writer, so it stands at *both*
  ends of every pipeline and the transit format colliding with the endpoint
  format is ordinary. =gpkg= → =gpkg= already works (it returns before the
  check), so the crate already contains the counterexample. The real work is
  fidelity, not the deletion: geosetta's round trip drops what =ogr2ogr=
  keeps (feature =id=, both =bbox=es, collection =name=), and on a same-format
  run "the target can't hold it" is no longer a defence — so a warning ships
  with it. Also restores the in-place guard the format check was accidentally
  providing. Scoping only.
- [ ] [[file:multi-geometry-columns.org][multi-geometry-columns.org]] — carry
  a second GeoParquet geometry column through the IR (=Feature::extra_geometries=)
  instead of rejecting it; text-fallback for every other target format.
  Scoping only.
- [ ] [[file:streaming-progress.org][streaming-progress.org]] — thread a
  throttled progress callback through each reader/writer so =--progress= can
  report live percentage on large files. The flag itself already ships and
  reports *per-stage*; what is unimplemented is the *intra-stage* percentage
  this plan is about.
- [ ] [[file:compression-encoders.org][compression-encoders.org]] — close the
  read/write asymmetry in =compress/=; DEFLATE first (real consumer: a
  compressed, not just stored, =.kmz= writer), LZ4/ZSTD encoders deferred
  behind it. Scoping only.
- [ ] [[file:arbitrary-geoparquet.org::*OPEN QUESTIONS][arbitrary-geoparquet.org — Brotli codec]] —
  last unimplemented Parquet compression codec (LZO/Hadoop-framed-LZ4 are
  edge cases; Brotli is the real gap).
- [ ] [[file:arbitrary-geoparquet.org::*7. Nested/repeated (list-valued) columns][arbitrary-geoparquet.org — list of structs / nested list]] —
  milestone 7 decodes a single-level list of scalars; a list of structs or a
  list nested inside another list still hard-rejects.
- [ ] [[file:spatial-index.org::*OPEN QUESTIONS][spatial-index.org — default =--rtree=?]] —
  whether GeoPackage's R*Tree extension should flip on by default now that
  =rtreecheck()=/GDAL validation cover the from-scratch node format.
- [ ] [[file:../project.org::Raster formats][project.org — raster format support]] —
  a second IR (coverage/grid model) beside the feature IR; further-out, not
  yet scoped into its own plan file.
