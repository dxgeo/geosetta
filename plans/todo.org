* Current Working Items
Live list of what's open right now — not the full historical plan index (see
[[file:README.org][README.org]] for that, ordered by dependency, everything
DONE included). Each entry is just a link to its real plan/section for detail;
check it off and remove it once the item ships or is shelved.

- [X] *Cross-repo:* =geoscribe/plans/wkt-identify.org= — *DONE, in geoscribe.*
  =geoscribe --identify= identifies an id-less =.prj= by name + ellipsoid
  validation and emits a definition, so the capability lost with
  =crs-registry='s removal is back through =--crs= composition. Geosetta needed
  *zero* changes, as predicted. One thing worth knowing on this side: where
  several CRSes fit a =.prj= equally well (39% of real Esri projected exports) geoscribe prints nothing and exits =2=, and =--crs='s hard error on
  empty input turns that into a loud pipeline failure — verified end to end.
  Remove this entry once read.
- [ ] [[file:multi-geometry-columns.org][multi-geometry-columns.org]] — carry

  instead of rejecting it; text-fallback for every other target format.
  Scoping only.
- [ ] [[file:streaming-progress.org][streaming-progress.org]] — thread a

  behind it. Scoping only.
