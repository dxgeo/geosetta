- [X] [[file:container-reconciliation.org][container-reconciliation.org]] —
  *COMPLETE 2026-10-13.* What happens to container content when the
  *destination* GeoPackage already has some. All six requirements built, in two
  passes the same day: § 3's set-union layer with § 5's refusals, then § 4's
  index construction. =src/geopackage/reconcile.rs= is the module, wired in
  =main.rs= — **the destination's container is merged rather than destroyed**,
  which clears =same-format-fidelity.org= M3b's last gate.

  A merge now dedupes the metadata pair by content, applies its id map to the
  references and dedupes those on the mapped values keeping the destination's
  stamp; set-unions tables and pyramids by name; and for a same-named **tile
  pyramid** unions the tiles on Requirement 54's key, reissuing the incoming
  side's rowids, ***building*** the index from the merged rows,
  recomputing =sqlite_sequence= behind them and *remapping* any row-scoped
  =gpkg_metadata_reference= to the tile it still means. Six refusals cover what
  has no union. /Measured: all **120** writing pairs across this tree's =.gpkg=
  fixtures produce files passing all three oracles; the other 36 refuse with a
  stated reason. For the built index the pragmas are **not** the test — a
  mis-sorted b-tree still holds one entry per row and passes =integrity_check=,
  so =sqlite_enforces_the_unique_behind_a_merged_pyramids_built_index= makes
  SQLite find a duplicate through it and refuse./

  *Three things worth keeping, none of them in the plan.* **§ 4 turned out
  cheap and D10's reversal is spent**: no producer emits an index this crate
  struggles with, so =compare_values='s =BINARY=-only scope stands and a
  =COLLATE=/=DESC= key is refused rather than approximated. **A built index is
  not byte-equal to a carried one** over identical rows — =encode_record=
  writes every integer as an 8-byte serial type where SQLite picks the
  narrowest — which is valid and worth knowing before anyone asserts byte
  equality against GDAL's output. And **two defects came out of § 3**,
  =handoff.org= entries 22 and 23, one of them reachable with no merge involved
  at all.

- [ ] [[file:edit-composability.org][edit-composability.org]] — let an
  external program modify the feature collection between a geosetta read and a
  geosetta write. The loop already runs; what is missing is fidelity — no
  transit format carries a full collection without loss, and four of the losses
  are silent (WKT drops every property, KML strings them, =fgb= drops nulls,
  =gpkg= booleans → ints). Also flags in-place-through-a-pipe, which overwrites
  the file today with a silently downgraded CRS. Scoping only.
